Palette check for the dashboard's colours
=========================================
Run on 2026-11-17 with validate_palette.py from the dataviz skill (the Claude Code bundled
skill, version 2.1.325), light mode, chart surface #fcfcfb. The validator is not part of
this repository, so this file is the record of what it reported. The colours come from
app/utils.py, one set per chart, in the order each map is defined there.

How to read it
- The eight categorical sets pass the lightness, chroma, colour-blindness and
  normal-vision checks. Every WARN is the contrast of aqua, yellow or magenta against the
  chart surface (below 3:1), which the validator accepts only with visible labels or a
  table view; every chart has a table view.
- "Discharge disposition" and "Test result" colour bars with status tokens, which are not a
  categorical palette, so the validator's categorical checks do not apply to them and
  report FAIL (the yellow warning token is lighter than the band; the neutral grey is
  below the chroma floor; Inconclusive and Pending share that grey). On both charts every
  bar carries its category name on the axis and its count.
- The shift chart's two sets are at the end: the palette in use (slots 4, 1, 7, all pairs)
  and the first choice (slots 4, 2, 8), which fails because orange and red are 7.1 apart.
